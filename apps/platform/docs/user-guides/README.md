# User Guides

End-user documentation for students, teachers, and administrators.

## Portals

- **Student Portal** — Lesson viewing, quizzes, games, progress tracking, offline support
- **Teacher Portal** — Student reports, assignment management, analytics
- **Admin Portal** — Subject/topic/subtopic management, lesson publishing, user management

## Key Features

- Offline-first lesson delivery
- Interactive quizzes with step-by-step grading
- Digital blackboard for show-your-work
- Progress tracking and analytics
- Payment integration (AzamPay)
