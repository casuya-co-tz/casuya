## Syllabus overview

**Chapter One: Using ICT tools to search for information**
- 1.1 Familiarising with various types of search engines and browsers
- 1.2 Utilising ICT tools to search for general information

**Chapter Two: Listening to various types of information**
- 2.1 Answering questions based on information from presentations/tasks
  - Listening to oral information
  - Responding to questions from others
- 2.2 Practising pronunciation of words from oral, audio and audio-visual sources

**Chapter Three: Producing short and coherent oral messages**
- 3.1 Forming simple structures
- 3.2 Producing short oral messages on particular topics (e.g., introducing oneself)

**Chapter Four: Developing vocabulary from conversations and written texts**
- 4.1 Writing new vocabulary from conversations and written texts
- 4.2 Constructing sentences using vocabulary acquired from conversations and written texts

**Chapter Five: Using appropriate grammar and vocabulary in oral and written contexts**
- 5.1 Using appropriate grammar in oral and written language tasks
- 5.2 Using appropriate vocabulary in oral and written language tasks

**Chapter Six: Reading texts for comprehension**
- 6.1 Identifying main ideas and supporting details from a text
- 6.2 Inferring meanings of unfamiliar words and expressions from a text

**Chapter Seven: Comprehending oral messages**
- 7.1 Synthesising ideas from a variety of oral sources
- 7.2 Summarising information from a variety of oral sources

**Chapter Eight: Responding through oral and written communication**
- 8.1 Responding appropriately in oral communication contexts
- 8.2 Responding appropriately in written communication contexts

**Chapter Nine: Using appropriate grammar and vocabulary for oral communication**
- 9.1 Using appropriate grammar for oral communication in a variety of contexts
- 9.2 Using appropriate vocabulary for oral communication in a variety of contexts

**Chapter Ten: Creating a variety of texts using appropriate tone and register**
- 10.1 Creating formal texts using appropriate tone and register
- 10.2 Creating informal texts using appropriate tone and register

New English main competences: 1.0 (1.1, 1.2, 2.1, 2.2, 2.3), 2.0 (3.1, 3.2,
4.1, 4.2), 3.0 (5.1, 5.2, 6.1, 6.2), 4.0 (7.1, 7.2, 8.1, 8.2, 9.1, 9.2),
5.0 (10.1, 10.2) = 21 specific competences.

**WEEK 1 — NO. 1A (DOUBLE, 80 min):** MC 1.0 | SC 1.1 Familiarising with
various types of search engines and browsers | MA "Familiarise with search
engines and browsers" | SA "Identify and use various types of search engines
(e.g., Google, Bing) and browsers (e.g., Chrome, Firefox)" | Resources:
Computers/tablets, internet (if available), textbook.
- Introduction (10): Asks students whether they have ever searched for
  information on a computer or phone and how they did it. / Share personal
  searching experiences. / Engagement in discussion
- Competence Development (30): Explains the difference between a search engine
  and a browser, demonstrating how to open a browser and run a search on
  Google and Bing. / Take detailed notes and follow the demonstrations. /
  Correct identification of search engines and browsers
- Design (25): Guides pairs in performing a practical search for a given topic
  using a search engine. / Run a guided practical search in pairs. /
  Correct completion of the search task
- Realization (15): Reviews pair results, addresses errors, and consolidates
  the key points on the board. / Present search results and answer questions. /
  Accuracy of search results presented

**WEEK 1 — NO. 1B (DOUBLE, 80 min):** SC 1.1 | MA "Practise using browsers" |

  double period. / Recall the two concepts. / Correct recall

  browser, type the query, read results, open a page, and save useful

  school community. / Perform a practice search in groups. / Correct
